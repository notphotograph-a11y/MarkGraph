# MarkGraph 需求文档（Phase 1 · MVP）

> 版本：1.0 ｜ 日期：2026-08-19 ｜ 状态：已定稿
> 本文档是开发、测试、验收的唯一依据。功能范围变更必须先改本文档。

## 1. 产品定位

MarkGraph 是一个**本地优先、自托管的网页版 Markdown 双链笔记应用**。功能骨架受常见双链笔记软件启发（文件树、编辑器、`[[双链]]`、反向链接、蜘蛛网图谱），视觉上提供五套可切换主题。

目标用户：单用户自托管，本机或受信任的内网使用。无鉴权。

核心价值排序（重要性从高到低）：

1. 蜘蛛网图谱：全库力导向关系图，可交互（悬停/点击/拖拽/缩放）
2. 双链写作流：`[[链接]]` 补全、跳转、断链提示创建、反向链接
3. 纯 Markdown 文件存储：vault 就是一个文件夹，任何编辑器都能打开，不锁格式
4. 可扩展底座：命令面板、事件总线、面板插槽，为 Phase 2/3 智能化功能预留

## 2. 功能需求

### F1 Vault 与文件树

| 编号 | 需求 |
|---|---|
| F1.1 | vault 为服务器本地一个文件夹（`VAULT_DIR` 环境变量指定），仅识别 `.md` 文件与子文件夹 |
| F1.2 | 左侧文件树按目录层级展示，文件夹可展开/折叠，点击 `.md` 在主区打开 |
| F1.3 | 文件树支持：新建笔记、新建文件夹、重命名、删除（右键菜单 + 菜单按钮） |
| F1.4 | 删除需二次确认；删除已打开的笔记时同时关闭对应标签页 |
| F1.5 | 文件被外部程序修改时，通过 SSE 推送，前端刷新文件树与已打开笔记的 mtime 提示 |
| F1.6 | 隐藏文件/文件夹（`.` 开头）不显示 |

### F2 编辑器

| 编号 | 需求 |
|---|---|
| F2.1 | CodeMirror 6 编辑器，支持基础 live preview：标题 `#`、加粗 `**` 等标记在非聚焦行折叠渲染 |
| F2.2 | `[[wikilink]]` 语法高亮为可点击 chip；支持 `[[笔记名]]`、`[[笔记名\|别名]]`、`[[笔记名#标题]]` |
| F2.3 | `#标签` 高亮；标签名允许中文、字母、数字、下划线、连字符 |
| F2.4 | 输入 `[[` 触发文件名 fuzzy 补全；`Escape` 关闭；选择项插入标准 wikilink |
| F2.5 | 点击存在的 wikilink → 打开目标笔记（新标签或激活已有标签）；点击断链 → 弹出「创建此笔记？」确认，创建后跳转 |
| F2.6 | Cmd+E 切换 编辑 / 阅读 模式；阅读模式为只读渲染视图（标题层级、链接、标签、列表、引用、代码块） |
| F2.7 | 自动保存：停止输入 1.5 秒或切换标签/失焦时 `PUT` 保存；标题栏显示保存状态（已保存/保存中） |
| F2.8 | 同名笔记以相对路径区分显示 |

### F3 反向链接与大纲

| 编号 | 需求 |
|---|---|
| F3.1 | 右栏显示「反向链接」面板：列出所有链接到当前笔记的笔记，每条含引用处上下文摘录（前后各约 40 字） |
| F3.2 | 点击反链条目跳转到来源笔记 |
| F3.3 | 右栏「大纲」面板：列出当前笔记的标题层级（h1-h4 缩进树），点击滚动定位到对应位置 |
| F3.4 | 索引在笔记保存、增删改名后增量更新，无需手动刷新 |

### F4 图谱视图

| 编号 | 需求 |
|---|---|
| F4.1 | 图谱以特殊标签页打开，展示全库力导向图：节点=笔记，边=wikilink 引用（含断链节点） |
| F4.2 | 节点大小随连接数变化；节点颜色按所在文件夹分组（图例可开关） |
| F4.3 | 交互：滚轮缩放、空白拖拽平移、节点拖拽（松开后固定新位置附近）、双击画布重置视图 |
| F4.4 | 悬停节点：高亮该节点及其直接邻居与边，其余淡化；显示笔记名 tooltip |
| F4.5 | 点击节点打开该笔记；当前打开笔记在图中高亮标记 |
| F4.6 | 500 篇笔记规模下保持流畅（canvas 渲染，力导向迭代不阻塞 UI） |

### F5 命令面板

| 编号 | 需求 |
|---|---|
| F5.1 | Cmd+P（Ctrl+P）打开命令面板，Esc 关闭，↑↓ 选择，Enter 执行 |
| F5.2 | 两类条目：文件（fuzzy 匹配文件名，回车打开）与命令（见命令注册表） |
| F5.3 | 命令注册表（初始命令）：新建笔记、打开图谱、切换编辑/阅读模式、切换主题×5、关闭当前标签、导入示例库 |

### F6 主题

| 编号 | 需求 |
|---|---|
| F6.1 | 5 套主题（见 `03-风格规范.md`）：玻璃 / 纸感 / 经典深色 / 纯黑 / 卡片；玻璃为默认 |
| F6.2 | 主题切换即时生效，选择持久化（localStorage），刷新后保持 |
| F6.3 | 所有颜色、圆角、字体经 CSS 变量 token 控制，主题间共享同一 DOM 结构 |

### F7 示例库

| 编号 | 需求 |
|---|---|
| F7.1 | 首次启动若 vault 为空：显示欢迎页，提供「导入示例库」按钮 |
| F7.2 | 示例库约 25 篇互链中文笔记（3 个文件夹分组、含标签、含断链演示），一键写入 vault |

### F8 扩展底座（Phase 2/3 预埋）

| 编号 | 需求 |
|---|---|
| F8.1 | 事件总线：`note:open` `note:save` `tree:change` `link:navigate` 等事件的注册与广播 |
| F8.2 | 面板插槽：右栏面板可注册（反链、大纲已注册，Phase 2 的「相关笔记」直接插入） |
| F8.3 | 命令 registry：F5.3 的机制本体 |

## 3. 非功能需求

| 编号 | 需求 |
|---|---|
| N1 | 后端默认只监听 `127.0.0.1`。绑定 `0.0.0.0` 仅用于反向代理后的部署，启动时打印无鉴权警告；不要把未保护端口暴露公网 |
| N2 | 文件 API 必须校验路径（resolve 后必须以 vault 根开头），拒绝路径穿越 |
| N3 | 无鉴权（单用户内网假设），但 API 仅接受 vault 内 `.md` 与目录操作 |
| N4 | 前端类型检查（tsc）与生产构建（vite build）零错误 |
| N5 | 界面文案全部中文；快捷键遵循 Mac 习惯（Cmd），Windows 降级 Ctrl |

## 4. Phase 1 明确不做

- 全文搜索、标签管理页、Canvas 白板、日记模板、多窗口
- AI 功能（Phase 2：embedding 索引、建议链接、语义搜索；Phase 3：vault RAG 问答）
- 多用户、鉴权、协作、移动端适配（响应式可用即可，不做专属优化）
- 插件系统（以事件总线 + 命令 registry + 面板插槽代替）

## 5. 验收标准（完成的定义）

1. F1-F7 全部条目可通过 `docs/04-测试清单.md` 逐项验证
2. `tsc` 与 `vite build` 零错误
3. 测试清单全绿（发现的 bug 修复并复测通过）
4. 界面通过去 AI 味审查并修复
5. 文档与示例库不含私人基础设施信息
