# MarkGraph 需求文档（Phase 1 · MVP）

> 版本：1.6 ｜ 日期：2026-08-23 ｜ 状态：v0.2.0 已定稿（插图 / 移动 Web / 鉴权+Docker）；v1.6 增补「外部 Agent 接入」（规划中，详见 `05-外部Agent接入需求.md`）
> 本文档是开发、测试、验收的唯一依据。功能范围变更必须先改本文档。

## 1. 产品定位

MarkGraph 是一个**自托管的网页版 Markdown 双链笔记应用**（客户端-服务器架构）。功能骨架受常见双链笔记软件启发（文件树、编辑器、`[[wikilink]]`、反向链接、蜘蛛网图谱），视觉上提供五套可切换主题。

> 术语边界（2026-08-20 勘误）：本项目**不是** local-first（本地优先）——浏览器客户端无离线能力，数据存于服务端文件系统。准确的承诺是：**数据主权**（纯 `.md` 文件、无云、无账号、无锁定）+ **自托管**（服务跑在用户自己的机器上，多端以浏览器远程访问同一服务）。离线优先 + 多端合并属于另一种产品形态（需文件同步/CRDT 层），不在本项目范围。

**产品愿景（2026-08-20 增补）**：面向**个人 NAS 自托管、随时随地多端访问**的笔记应用。一个服务跑在用户的 NAS/自有服务器上，任何设备的浏览器（电脑/手机/平板）访问同一个笔记库。当前阶段专注把 **Web 端功能**做完整；后续演进方向与顺序：

1. Web 功能完善（写作流、AI 富集、问答、设置、文件夹页、全文搜索、正文插图）
2. 移动 Web 适配（"随时随地"的主力设备是手机，响应式从"可用"升为"好用"）
3. 部署安全与分发：访问鉴权（非回环必须口令）+ Docker 镜像（群晖/威联通/绿联）
4. 多端客户端（原生/壳应用）——REST + SSE API 已为其就绪
5. Agent 生态接入（MCP）：笔记库全部能力（增删改查、整理、索引、问答）开放给任意外部 AI agent 调用（v1.6 增补，见 §11 与 `05-外部Agent接入需求.md`）

目标用户：单用户自托管。回环开发可无口令；局域网 / Docker 必须设口令。

核心价值排序（重要性从高到低）：

1. 蜘蛛网图谱：全库力导向关系图，可交互（悬停/点击/拖拽/缩放）
2. 双链写作流：`[[链接]]` 补全、跳转、断链提示创建、反向链接
3. 纯 Markdown 文件存储：vault 就是一个文件夹，任何编辑器都能打开，不锁格式
4. 可扩展底座：命令面板、事件总线、面板插槽，为 Phase 2/3 智能化功能预留

## 2. 功能需求

### F1 Vault 与文件树

| 编号 | 需求 |
|---|---|
| F1.1 | vault 为服务器本地一个文件夹（`VAULT_DIR` 环境变量指定），文件树仅识别 `.md` 与子文件夹；图片附件见 F19，存于 `attachments/` 且不出现在树中 |
| F1.2 | 左侧文件树按目录层级展示，文件夹可展开/折叠，点击 `.md` 在主区打开 |
| F1.3 | 文件树支持：新建笔记、新建文件夹、重命名、删除（右键菜单 + 菜单按钮） |
| F1.4 | 删除需二次确认；删除已打开的笔记时同时关闭对应标签页 |
| F1.5 | 文件被外部程序修改时，通过 SSE 推送，前端刷新文件树与已打开笔记的 mtime 提示 |
| F1.6 | 隐藏文件/文件夹（`.` 开头）不显示 |

### F2 编辑器

| 编号 | 需求 |
|---|---|
| F2.1 | CodeMirror 6 编辑器，支持基础 live preview：标题 `#`、加粗 `**` 等标记在非聚焦行折叠渲染 |
| F2.2 | `[[wikilink]]` 语法高亮为可点击 chip；支持 `[[笔记名]]`、`[[笔记名\|别名]]`、`[[笔记名#标题]]` |
| F2.3 | `#标签` 高亮；标签名允许中文、字母、数字、下划线、连字符 |
| F2.4 | 输入 `[[` 触发文件名 fuzzy 补全；`Escape` 关闭；选择项插入标准 wikilink |
| F2.5 | 点击存在的 wikilink → 打开目标笔记（新标签或激活已有标签）；点击断链 → 弹出「创建此笔记？」确认，创建后跳转 |
| F2.6 | Cmd+E 切换 编辑 / 阅读 模式；阅读模式为只读渲染视图（标题层级、链接、标签、列表、引用、代码块） |
| F2.7 | 自动保存：停止输入 1.5 秒或切换标签/失焦时 `PUT` 保存；标题栏显示保存状态（已保存/保存中） |
| F2.8 | 同名笔记以相对路径区分显示 |

### F3 反向链接与大纲

| 编号 | 需求 |
|---|---|
| F3.1 | 右栏显示「反向链接」面板：列出所有链接到当前笔记的笔记，每条含引用处上下文摘录（前后各约 40 字） |
| F3.2 | 点击反链条目跳转到来源笔记 |
| F3.3 | 右栏「大纲」面板：列出当前笔记的标题层级（h1-h4 缩进树），点击滚动定位到对应位置 |
| F3.4 | 索引在笔记保存、增删改名后增量更新，无需手动刷新 |

### F4 图谱视图

| 编号 | 需求 |
|---|---|
| F4.1 | 图谱以特殊标签页打开，展示全库力导向图：节点=笔记，边=wikilink 引用（含断链节点） |

## 6. Phase 2 需求：AI 自动富集（v1.1 增补 · 2026-08-19）

> 定位：反链与反链摘录在 Phase 1 已全自动（由 wikilink 索引派生）。本节补齐「自动生成」：标签、摘要、笔记间连接全部由 AI 在后台完成，默认全自动，可一键撤销。

### F9 AI 接入底座

| 编号 | 需求 |
|---|---|
| F9.1 | AI 统一走 OpenAI 兼容接口（支持 newAPI 等网关），服务端 `.env` 配 `AI_BASE_URL` / `AI_API_KEY` / `AI_CHAT_MODEL` / `AI_EMBED_MODEL`；未配置时应用照常运行，「智能」面板显示未配置引导 |
| F9.2 | AI 设置持久化于 `VAULT_DIR/.markgraph/settings.json`（点开头目录，文件树不显示）：`autoTags`、`autoSummary`、`autoLinks`（off/suggest/auto）、`maxAutoLinks`；改完即时生效 |
| F9.3 | 服务端串行任务队列：笔记保存后防抖触发富集（默认 8s）；正文内容 hash 未变则跳过；空笔记（正文 < 20 字）不调用 AI |
| F9.4 | 所有 AI 写入前先备份到 `.markgraph/backups/`，并记录改动前后内容；面板与 API 提供「撤销上次 AI 修改」 |
| F9.5 | AI 写入采用乐观并发保护：落盘前文件若已被人工改动，放弃本次写入并择机重试，绝不覆盖人工编辑 |

### F10 自动标签与摘要

| 编号 | 需求 |
|---|---|
| F10.1 | LLM 为笔记生成 `tags`（3-5 个）与 `summary`（一句话摘要），写入 frontmatter 的 `tags` / `summary` 键，正文不动；已有 frontmatter 其他键原样保留 |
| F10.2 | frontmatter `tags` 并入标签索引（与正文 `#标签` 同源）；人工写的标签不删除、只合并去重 |
| F10.3 | 阅读模式隐藏 frontmatter 块；编辑模式原样可见可改 |
| F10.4 | 手动触发：命令面板「AI：为当前笔记生成」与「AI：为全库生成索引」（带 done/total 进度） |

### F11 自动连接与相关笔记

| 编号 | 需求 |
|---|---|
| F11.1 | embedding 索引：笔记正文向量化（向量按正文 hash 缓存），相关笔记按余弦相似度计算 |
| F11.2 | 右栏新增「智能」面板：显示 AI 摘要、标签、相关笔记 top N（点击跳转）、建议链接（目标 + 理由 + 定位原句） |
| F11.3 | 建议链接由 LLM 依据当前正文与语义候选笔记生成 `{target, reason, anchor}`；已链接目标、自身、不存在的目标不再建议 |
| F11.4 | 应用建议 = 在 anchor 所在行末插入 `[[目标]]`；`autoLinks=auto` 时自动应用（单次上限 `maxAutoLinks`，默认 3），`=suggest` 时在面板点击应用 |
| F11.5 | 撤销：恢复本次 AI 修改前的完整内容；若文件此后被人工改过则拒绝并提示 |

### F12 语义搜索

| 编号 | 需求 |
|---|---|
| F12.1 | 命令面板输入自然语言（≥ 4 字）时调用语义检索，语义相近笔记以独立分组展示在最上方；AI 未配置时静默降级为原有文件名 fuzzy |

### N9 非功能（AI 相关）

| 编号 | 需求 |
|---|---|
| N9.1 | AI 请求带超时（chat 120s / embedding 60s）；失败只记录与面板提示，不影响写作与保存主流程 |
| N9.2 | API key 只存在于服务端 `.env`，不经任何 API 下发到浏览器 |
| N9.3 | `.markgraph/` 内缓存（向量、富集状态、设置、备份）不入 git、不出现在文件树 |

### Phase 2 明确不做

- RAG 问答（Phase 3）
- 建议链接以外的正文改写（AI 不改写句子，只在行末追加 wikilink）

## 7. Phase 3 需求：RAG 问答（v1.2 增补 · 2026-08-19）

> 定位：对整个 vault 提自然语言问题，答案只依据库内笔记，引用可跳转。多端原生客户端仍是后续演进方向，不在本仓库范围。

### F13 RAG 问答

| 编号 | 需求 |
|---|---|
| F13.1 | 「问答」以特殊标签页打开（命令面板「打开问答」、智能面板入口）；AI 未配置时显示配置引导 |
| F13.2 | 检索：富集时笔记按「当前标题 + 段落」切块（目标 ≤600 字）向量化，块向量随笔记缓存；问答按问题向量取每篇笔记最佳块、全库 top 6 作为上下文 |
| F13.3 | 生成：答案流式输出；模型引用来源须用 `[[笔记名]]`，在答案中可点击跳转；来源笔记另以 chip 列出 |
| F13.4 | 多轮：会话内追问携带最近对话历史（浏览器内存，关闭标签即清空，不落盘） |
| F13.5 | 库内无向量时提示先「全库生成」并提供按钮；上下文不足时模型须明示「笔记库中没有足够信息」，不得编造 |

### N10 非功能（问答相关）

| 编号 | 需求 |
|---|---|
| N10.1 | 问答请求走 OpenAI 兼容 `stream` 接口；网关不支持流式时自动降级为一次性返回 |
| N10.2 | 流式响应中的错误经 SSE `error` 事件回传前端提示，不静默失败 |

| F19.5 | 二进制走独立 `/api/file`，不经 `readNote`/`writeNote`；不把整个 vault 挂静态目录 |

明确不做：SVG、PDF、音视频、`![[wiki 嵌入]]`、把附件列在文件树。

## 11. 外部 Agent 接入 · MCP（v1.6 增补 · 2026-08-23）

> 定位：**人用浏览器，agent 用 MCP**。把笔记库的全部能力——新建、读取、修改、整理、删除、建立索引、搜索、问答——以 MCP 工具形式开放给外部 AI agent（Claude Code、ZCode、Cursor 等），全程可审计、可撤销、不破坏人工编辑。工具清单、演练场景与验收细节见 `05-外部Agent接入需求.md`，本节只登记范围与边界。

### F22 MCP 接入底座

| 编号 | 需求 |
|---|---|
| F22.1 | 服务端内嵌 MCP 端点（Streamable HTTP，`/mcp`，与主服务同端口），复用现有 service 层（fs-vault / ai）；`/api/*` 保持浏览器私有契约，对外唯一稳定承诺是 MCP 工具 schema |
| F22.2 | API Token 鉴权（Bearer），与浏览器 Cookie 会话相互独立；分 `read` / `read-write` 两档作用域，设置对话框可生成与吊销 |
| F22.3 | 工具覆盖全部功能域：笔记 CRUD、附件、查询（树 / 全文 / 反链 / 图谱 / 标签 / 语义）、整理（重命名并更新引用、批量替换、体检报告）、AI（富集 / 全库索引 / 建议链接 / 撤销 / RAG 问答）、回收站与审计 |
| F22.4 | AI 未配置时相关工具明确报「未配置」，不静默降级——agent 需要知道真实状态 |

### F23 服务端索引与整理能力（Web 端同受益）

| 编号 | 需求 |
|---|---|
| F23.1 | 链接索引（wikilink → nodes / edges / backlinks / tags）从浏览器下沉为服务端共用模块，Web 前端与 MCP 同源取数、共用同一套解析规则 |
| F23.2 | `rename_note` 支持同步更新全库指向目标的 `[[wikilink]]`（MCP 默认开启；Web 端是否跟进另议） |
| F23.3 | 新增整理类只读工具：全库断链清单、孤立笔记、标签清单、体检报告（`health_check`）；整理策略由 agent 编排原子工具完成，产品不内置固定流程 |
| F23.4 | agent 通道删除一律进回收站（`.markgraph/trash/`，保留上限 200 份或 30 天），提供查询与恢复工具；浏览器删除行为不变 |

### N12 非功能（Agent 接入相关）

| 编号 | 需求 |
|---|---|
| N12.1 | token 只存 SHA-256、常量时间比较；未配置 token 时 `/mcp` 一律 401；token 不出现在任何日志与接口回显中 |
| N12.2 | 复用 N2 路径校验；MCP 工具禁止触碰 `.markgraph/`（回收站与审计经专用工具访问） |
| N12.3 | 审计日志 `.markgraph/audit.jsonl`：记录每次 agent 调用的时间、工具、参数摘要与结果，提供查询工具 |
| N12.4 | 写类工具限速（默认 60 次/分钟，可配）；写笔记支持乐观并发（`expected_mtime` 冲突 409），agent 与人工编辑互不覆盖 |
| N12.5 | 工具描述与错误信息面向 agent 优化（如路径不存在时返回相近候选），减少试错循环 |
