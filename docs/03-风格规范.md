# MarkGraph 风格规范（Phase 1）

> 版本：1.0 ｜ 日期：2026-08-19 ｜ 依据：`01-需求.md` F6
> 规则：五套都是原创诠释。正式应用按玻璃套的结构落地；其余四套降级为配色 token 主题（共享同一 DOM 结构）。
> 风格参考库：[TonnyWong1052/UI-Prompt](https://github.com/TonnyWong1052/UI-Prompt)（glassmorphism / flatDesign / minimalism 家族）。

## 0. 共同骨架（五套共有的功能结构，不因风格而缺失）

文件树 / 标签页 / 编辑区 / 反链+大纲面板 / 图谱入口 / 命令面板（Cmd+P）。风格差异体现在：导航位置与形态、面板材质、间距密度、圆角阴影、字体气质、组件样式。

## ① obsidian — 经典深色

**气质**：紧凑、工具感、深灰 + 紫。

| Token | 值 |
|---|---|
| --bg | #1e1e1e（主编辑区） |
| --bg-panel | #1a1a1a（两侧栏） |
| --bg-elevated | #262626（悬浮菜单/命令面板） |
| --text / --text-muted | #dcddde / #9a9a9a |
| --accent | #8b6cef（紫） |
| --border | #2f2f2f（1px，无处不在但低调） |
| --radius | 4px（tab 6px） |
| --font-ui / --font-content | 13px 系统无衬线 / 16px `"Inter", -apple-system, "PingFang SC"` 行高 1.6 |

**结构**：左侧文件树 240px（无 ribbon）；顶部 tab 栏 36px，active tab 带下划线+浅底；右栏 280px。悬停态 `rgba(255,255,255,.055)`；active 态 `rgba(255,255,255,.09)`。wikilink 颜色 #a882ff，断链 #e16d76 虚线下划线。命令面板居中 640px，无遮罩模糊，边框 #3a3a3a。

## ② apple — 玻璃

**气质**：浅色、通透、大留白、精确。整窗有「悬浮玻璃面板」感。

| Token | 值 |
|---|---|
| --bg | #f0f0f3（桌面感，铺极淡多色光斑渐变，radial-gradient 叠 2-3 层） |
| --bg-panel | rgba(255,255,255,.62) + `backdrop-filter: blur(28px) saturate(1.8)` |
| --bg-elevated | rgba(255,255,255,.78) + blur(40px)，投影 0 12px 40px rgba(0,0,0,.14) |
| --text / --text-muted | #1d1d1f / #6e6e73 |
| --accent | #0071e3（蓝），accent-contrast #fff |
| --border | rgba(0,0,0,.08)；玻璃面板内描边 rgba(255,255,255,.65) |
| --radius | 12px（面板 16px，按钮 capsule） |
| --font-ui / --font-content | 13px -apple-system / 16px 同栈，标题 -0.02em 字距 |

**结构自由发挥**：三栏均为独立玻璃浮板，浮板间 10px 缝隙露出桌面光斑背景；tab 栏左侧放装饰性红黄绿交通灯（纯装饰，标注于实现中不参与交互）；编辑/阅读切换用分段控件（segmented control）；命令面板为顶部下拉式玻璃面板 + 轻投影。悬停态 rgba(0,0,0,.04)，过渡 150ms ease-out。

## ③ meta — 卡片

**气质**：友好、社交、卡片化。信息块都装进白色圆角卡片，浅灰画布，蓝色贯穿。

| Token | 值 |
|---|---|
| --bg | #f0f2f5（浅灰画布） |
| --bg-panel / --bg-elevated | #ffffff（卡片） |
| --text / --text-muted | #050505 / #65676b |
| --accent | #0064e0（蓝） |
| --border | #e4e6eb（卡片描边与分隔线） |
| --radius | 12px（按钮 pill，头像/圆点 full） |
| --font-ui / --font-content | 14px `"Segoe UI", Helvetica, "PingFang SC"` / 16px 同栈 |
| 阴影 | 0 1px 2px rgba(0,0,0,.1), 0 1px 8px rgba(0,0,0,.1)（卡片浮起） |

**结构自由发挥**：顶部全局导航栏（白色，含应用名、搜索胶囊、图谱按钮、头像圆点）；下方三栏皆为卡片：文件树卡片、编辑卡片（含自己的 tab 条）、右栏两张堆叠卡片（反链/大纲）。命令面板居中卡片 + 灰色遮罩 rgba(0,0,0,.4)。按钮主色蓝底白字 pill，次级浅蓝 #e7f3ff 底。

## ④ x — 纯黑

**气质**：极致黑、高对比、无装饰、边缘贴边。信息密度高，视觉噪音趋零。

| Token | 值 |
|---|---|
| --bg | #000000 |
| --bg-panel | #000000（列间仅 1px #2f3336 分隔，不用底色区分） |
| --bg-elevated | #16181c（菜单/命令面板） |
| --text / --text-muted | #e7e9ea / #71767b |
| --accent | #1d9bf0（蓝，仅用于 active 指示与链接） |
| --border | #2f3336 |
| --radius | 按钮胶囊 full；其余 0-4px（去圆角化） |
| --font-ui / --font-content | 14px 系统栈（紧凑字距） / 15px 行高 1.65 |

**结构自由发挥**：三列 edge-to-edge 贴满视口无外边距；最左窄图标导航列（56px：logo/图谱/新建/主题 四个图标钮）；中列 tab 条为「文字+底部圆条」；右栏无卡片直接列表。命令面板顶部下弹（非居中），条目 hover #16181c。悬停通用 rgba(231,233,234,.08)。

## ⑤ paper — 纸感

**气质**：暖纸白、墨色文字、衬线标题、编辑器呼吸感。像在纸上写字，界面退到几乎不可见。

| Token | 值 |
|---|---|
| --bg | #fbfaf7（暖纸白） |
| --bg-panel | #f5f3ee（侧栏略深一档的纸） |
| --bg-elevated | #fffdf9 + 1px #e6e2d9 边（无投影或 0 2px 8px rgba(60,50,30,.06)） |
| --text / --text-muted | #1c1b18 / #6f6a5f |
| --accent | #b45309（赭墨，链接与 active 用） |
| --border | #e6e2d9（发丝线） |
| --radius | 2px（近直角） |
| --font-ui / --font-content | 13px 系统无衬线 / 17px，**标题用衬线** `"Songti SC", Georgia, serif` |

**结构自由发挥**：三栏以发丝线分隔而非底色；tab 做成「文件夹标签」样式（梯形/上圆角小块）；正文栏限制 max-width 46rem 居中，模拟纸张行宽；反链面板像脚注区。命令面板极简线框（白纸+细边+无阴影）。

## 决策与落地

**已选定：② apple（玻璃）为正式应用的结构与默认主题。**

- 主题顺序：apple（默认）/ paper / obsidian / x / meta，全部可切换（F6.2/F6.3）。对外显示名为玻璃 / 纸感 / 经典深色 / 纯黑 / 卡片。
- **玻璃实现约束**：`backdrop-filter` 仅用于侧栏、标签栏、命令面板等「壳」层；编辑器内容面保持不透明稳定底色（长会话可读性与性能）；提供 `prefers-reduced-transparency` 媒体查询回退（玻璃降级为实色）
- 小样页 `style-samples/index.html` 保留在仓库中作主题预览（支持 `#<theme>/graph` 直达）

## 动效规范（v1.1 增补 · 2026-08-19）

**通则**：只动 `transform` / `opacity`（折叠箭头等例外注明）；hover/按压 90–140ms、面板入场 130–240ms，全部 ≤300ms；色彩类过渡所有主题统一强 ease-out `cubic-bezier(0.23,1,0.32,1)`，不回弹；入场位移按主题分化；`prefers-reduced-motion` 下动画与过渡近乎关停（保留色彩可读性）。动效全部经 CSS 变量 token 驱动（延续 F6.3 单 DOM 多主题），新动效只许引用 token，不许写死曲线时长。

**每主题一套运动性格**（`--mg-dur-hover` / `--mg-dur-panel` / `--mg-ease-pop` / `--mg-pop-y` / `--mg-pop-scale`）：

| 主题 | hover | 面板入场 | 入场曲线 | 位移/缩放 | 性格 |
|---|---|---|---|---|---|
| 玻璃 apple | 130ms | 210ms | iOS 抽屉 `(0.32,0.72,0,1)` | 10px / 0.985 | 流体、轻盈 |
| 纸感 paper | 120ms | 160ms | 强 ease-out | 4px / 不缩放 | 克制、利落 |
| 经典深色 obsidian | 120ms | 180ms | 强 ease-out | 6px / 不缩放 | 中性、工具感 |
| 纯黑 x | 90ms | 130ms | 强 ease-out | 2px / 不缩放 | 极速、即时 |
| 卡片 meta | 140ms | 240ms | easeOutBack `(0.34,1.4,0.64,1)` | 8px / 0.96 | 轻回弹、playful |

**已落地动效**：交互面（按钮/链接/输入）色彩过渡；命令面板遮罩淡入 + 面板按主题入场（关闭保持即时，高频操作不拖尾）；标签页激活下划线从中线展开；问答消息与欢迎/空态轻抬升淡入；主题切换经 View Transition API 全页交叉淡化（不支持或 reduced-motion 时瞬切）。明确**不做**：Cmd+P 级高频操作的关闭动画、文件树高度动画（布局抖动）、图谱节点入场（d3 力导向自带运动）。
