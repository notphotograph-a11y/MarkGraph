# MarkGraph

本地优先、自托管的网页版 Markdown 双链笔记。

文件树、`[[wikilink]]`、反向链接、力导向图谱都在浏览器里完成。笔记就是文件夹里的纯 `.md` 文件，任何文本编辑器都能打开同一目录。

当前是 **Phase 3**：核心写作流 + AI 自动富集 + 库内问答可用。多端原生客户端是后续演进。

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm run dev          # Vite :5173  +  Fastify :7710
```

浏览器打开 http://127.0.0.1:5173 。空库会提示导入一份约 25 篇互链的中文示例笔记。

生产构建：

```bash
npm run build
npm start            # 默认 http://127.0.0.1:7710
```

环境变量（复制 `.env.example` 为 `.env`）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `HOST` | `127.0.0.1` | 监听地址。本机开发保持默认。 |
| `PORT` | `7710` | 端口 |
| `VAULT_DIR` | `~/MarkGraph-vault` | 笔记库文件夹，位于仓库外，不进 git |
| `AI_BASE_URL` | 空 | OpenAI 兼容接口地址（如 newAPI 网关的 `/v1`）。四项 AI 变量都配置后 AI 功能开启 |
| `AI_API_KEY` | 空 | 网关密钥，只存在服务端 |
| `AI_CHAT_MODEL` | 空 | 生成标签/摘要/建议链接的模型 |
| `AI_EMBED_MODEL` | 空 | 向量模型（相关笔记与语义搜索用） |

## AI 自动富集（Phase 2）

配置好上面四个 AI 变量后，**保存笔记即自动完成**：

- **标签与摘要**写入笔记 frontmatter（`tags` / `summary`），正文不动，阅读模式不显示
- **相关笔记**：右栏「智能」面板按语义相似度展示
- **自动连接**：AI 挑选强相关笔记，把 `[[链接]]` 插到对应原句所在行末（默认全自动，可在面板切「仅建议/关闭」）
- **语义搜索**：命令面板输入自然语言，语义相近的笔记排最前
- **库内问答**：「问答」标签页（命令面板打开）对整个 vault 提问，答案流式生成、只依据库内笔记，引用 `[[链接]]` 与来源笔记可点击跳转
- 每次 AI 写入都有备份（`vault/.markgraph/backups/`），面板可一键**撤销**；正文未变不重复调用

反向链接与反链摘录不需要 AI——它们从 `[[wikilink]]` 索引实时派生。AI 只负责「生成」，不负责「维护」。

## 安全

**没有登录、没有鉴权。** 能访问这个端口的人就能读写整个笔记库。

默认只监听本机回环地址。如果改成 `0.0.0.0`（例如放在反向代理后面），启动时会打印警告，但不会拒绝启动。不要把未加保护的端口暴露到公网。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Cmd/Ctrl+P` | 命令面板（打开笔记 / 切换主题 / 新建） |
| `Cmd/Ctrl+E` | 编辑 ⇄ 阅读 |
| `Esc` | 关闭命令面板 |

## 主题

五套可切换主题，默认「玻璃」。选择会记在 `localStorage`。

| 内部 id | 显示名 |
|---|---|
| `apple` | 玻璃 |
| `paper` | 纸感 |
| `obsidian` | 经典深色 |
| `x` | 纯黑 |
| `meta` | 卡片 |

独立预览页：[style-samples/index.html](style-samples/index.html)（浏览器直接打开）。
