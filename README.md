# MarkGraph

本地优先、自托管的网页版 Markdown 双链笔记。

文件树、`[[wikilink]]`、反向链接、力导向图谱都在浏览器里完成。笔记就是文件夹里的纯 `.md` 文件，任何文本编辑器都能打开同一目录。

当前是 **Phase 1**：核心写作流已经能用。语义搜索、建议链接、RAG 问答还没做。

## 快速开始

需要 Node.js 20+。

```bash
npm install
npm run dev          # Vite :5173  +  Fastify :7710
```

浏览器打开 http://127.0.0.1:5173 。空库会提示导入一份约 25 篇互链的中文示例笔记。

生产构建：

```bash
npm run build
npm start            # 默认 http://127.0.0.1:7710
```

环境变量（复制 `.env.example` 为 `.env`）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `HOST` | `127.0.0.1` | 监听地址。本机开发保持默认。 |
| `PORT` | `7710` | 端口 |
| `VAULT_DIR` | `~/MarkGraph-vault` | 笔记库文件夹，位于仓库外，不进 git |

## 安全

**没有登录、没有鉴权。** 能访问这个端口的人就能读写整个笔记库。

默认只监听本机回环地址。如果改成 `0.0.0.0`（例如放在反向代理后面），启动时会打印警告，但不会拒绝启动。不要把未加保护的端口暴露到公网。

## 快捷键

| 按键 | 作用 |
|---|---|
| `Cmd/Ctrl+P` | 命令面板（打开笔记 / 切换主题 / 新建） |
| `Cmd/Ctrl+E` | 编辑 ⇄ 阅读 |
| `Esc` | 关闭命令面板 |

## 主题

五套可切换主题，默认「玻璃」。选择会记在 `localStorage`。

| 内部 id | 显示名 |
|---|---|
| `apple` | 玻璃 |
| `paper` | 纸感 |
| `obsidian` | 经典深色 |
| `x` | 纯黑 |
| `meta` | 卡片 |

独立预览页：[style-samples/index.html](style-samples/index.html)（浏览器直接打开）。
